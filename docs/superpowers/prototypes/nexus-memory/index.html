ONE SHAPE, AN ICON PER TYPE

Every packet is the same small square. Its pixel icon says what kind of memory it carries.

Its frame says which way it goes:

  • cyan: from the archive to the agent;
  • violet: from the agent to the archive;
  • white: a guard stopping the agent.

Not green or amber: on the ship green means done and CI green, yellow means working, orange means needs you.

Click the rack beside mnemo-desktop, a packet, or a robot.

ROBOT STATES

Today a robot wears a small badge for what it does. The proposal drops the badge: the pose says the state (an existing sprite), a held prop says the action (one prop for every class), a CSS motion makes it read at a glance, and the existing particles stay, now coming off the prop. The halo under the feet keeps the ship's state colours and takes over the colour the badge's border carried (CI red: orange; CI running: yellow). The props are drawn in the sprites' palette, so the CI-green flag is not green: the green is the halo's.
